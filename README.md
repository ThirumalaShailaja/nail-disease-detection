# Nail Disease Detection using Deep Learning

## Overview
This project is a Deep Learning based web application that detects nail diseases from uploaded nail images using a trained CNN model.

## Technologies Used
- Python
- Flask
- TensorFlow
- Keras
- HTML
- CSS
- JavaScript

## Features
- Upload nail image
- Predict nail disease
- User-friendly interface
- Deep learning image classification
